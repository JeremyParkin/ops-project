No backgrounds. Transparent, cropped tight to the ink.
No live text — the wordmark is outlined, no font needed.
No strokes. Two brass shapes and the wordmark; nothing else.

The mark
  Two filled brass paths. The groove is EMPTY — no fill of any kind — so
  it shows whatever is behind it. Same file works on paper, graphite or photo.

    sliver  M62 88 A50 50 0 0 0 12 38 L12 29.75 A58.25 58.25 0 0 1 70.25 88 Z
  Groove = stroke 11.5 on r 64 about (12,88), converted to outline.
  Fixed proportion at every size. Never re-weight it.

Colours — two per file, never more
  Brass    #C8913A   the mark, always
  Graphite #1A1B18   wordmark, light grounds

Wordmark
  Space Grotesk Medium outlines, lowercase. Dotless i, square tittle at stem
  width (0.105em), inset 0.075em from the stem's left edge.
  L1 tracking -0.04em · L3 tracking -0.03em

Alignment — as drawn in the brand board
  L1  mark box 1.13x the wordmark's size, centred on the text's line box,
      gap 0.435x. The mark's ink overhangs the k's top and the baseline.
  L3  mark box 1.20x, gap 0.45x, mark box left edge = text box left edge.

Clearspace
  The mark's own width on all sides.
